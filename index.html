Methodology: pages through GET /api/v2/transactions?filter=validated on quaiscan.io using keyset pagination, reading each transaction's sender (and optionally recipient) address into per-window Sets. "Active wallet" = an address that sent (or, with the toggle on, also received) at least one transaction in that window. Fast mode estimates block heights at the 24h/7d/30d boundaries from two calibration reads of quaiscan.io's block list, then runs several pagination streams concurrently across time slices instead of one stream walking all 30 days — each slice scans slightly past its boundary to avoid gaps from estimation drift, and duplicate transactions from that overlap are deduped by hash before counting. If calibration fails for any reason, it falls back automatically to a single sequential scan.
